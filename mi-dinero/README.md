# Mi Dinero

App web personal de presupuesto: resumen del mes, apuntar movimientos, presupuesto y viajes.

- Web: GitHub Pages (este repo, público, solo código).
- Datos: `datos.json` en un repo **privado** aparte (`mi-dinero-datos`), sincronizado con un token de GitHub desde Ajustes.
- Sin token, los datos se guardan solo en el dispositivo.
